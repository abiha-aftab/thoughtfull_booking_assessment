# AI usage

This repository was built in Cursor with a coding agent.

The agent proposed the MERN layout and implemented each milestone: the monorepo, the API, authentication, availability, booking and reminders, the React screens, and this delivery pass. The decisions in `DECISIONS.md` were made during that work and written down so the behavior is not hidden in the code.

The author set the constraints, reviewed each milestone, and made the commits. The agent did not commit or push. Tests were run before a milestone was handed over, and the booking screens were also exercised in a browser against a local API.

Generated code was kept when it matched the requirements and the existing style, and changed when a test or a browser pass showed it did not. The fictional accounts, the seed password, and the copy in the README were chosen for a local demo. No assessment PDF, `.env` file, or real personal data is in the repository.
